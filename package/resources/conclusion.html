Installed

Deckhand is running (look for it in the menu bar). Two quick steps to finish:

  1. Allow Deckhand to control Teams. macOS will ask — or open System Settings → Privacy & Security and switch on Deckhand under Accessibility (on macOS 27 this pane is called Device Control and Data Access). This is how it presses Teams' mute and camera buttons and sees when you're in a call. If it's already switched on but the menu bar icon still shows a warning, choose Reset Permission & Ask Again… from the Deckhand menu.
  2. Add the Stream Deck plugin. Confirm the prompt Stream Deck shows, then drag actions from the Deckhand category onto your keys. If you missed the prompt, use Install Stream Deck Plugin… from the Deckhand menu bar icon.

The first time you switch on auto-mute, macOS also asks for Microphone access. It only measures loudness — audio is never recorded or sent anywhere.

If something isn't working, click the Deckhand icon in the menu bar — it says what's missing (permission to control Teams, Teams not running, no call detected, microphone not audible). Export Logs… in that menu saves a zip of logs and diagnostics you can send for troubleshooting.

macOS may also show “Deckhand added items that can run in the background” — keep it allowed (System Settings → General → Login Items & Extensions), or it won't start at login.

Check it any time with curl localhost:8942/status in Terminal.

Homey: the Homey app is installed on your Homey Pro, not on this Mac. If this Mac's address changed, update the device's Daemon address setting in Homey.
